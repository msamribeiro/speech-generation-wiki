# Scaling Rich Style-Prompted Text-to-Speech Datasets

**Paper:** [https://aclanthology.org/2025.emnlp-main.180](https://aclanthology.org/2025.emnlp-main.180)

**One-sentence contribution:** ParaSpeechCaps is the first large-scale (2709 hours total) open-source dataset annotating speech with 59 rich paralinguistic style tags (both intrinsic speaker-level and situational utterance-level), enabling instruction-conditioned TTS models to achieve substantially better style consistency and naturalness.

## Problem

Style-prompted TTS requires training data pairing each utterance with a natural-language style description. Existing large-scale datasets (Parler-TTS training data, PromptTTS2) only annotate basic, signal-processable tags (pitch level, speed, gender) that cover a narrow style space. Human-annotated datasets with rich abstract tags (LibriTTS-P, Expresso, EARS) cover at most 46 rich tags but are tiny (<100 hours). No large-scale open-source dataset covers both rich intrinsic (speaker identity: guttural, shrill, husky) and situational (utterance emotion: pained, animated, whispered) tags simultaneously — the combination needed to train models that respond to complex, compositional style prompts.

## Method

**Taxonomy.** 59 style tags organized by two axes: intrinsic (33 tags, speaker-level) vs. situational (26 tags, utterance-level), and rich (subjective, requires annotation) vs. basic (extractable via signal processing). 11 style factors with ~5 tags each.

**PSC-Base (282 hours, human-annotated).** Amazon Mechanical Turk annotators label speakers from VoxCeleb (594 celebrities), Expresso, and EARS with rich intrinsic tags. Each speaker is presented as a 20–40 second audio collage; annotators write ≥3 style tags. Tags retained if ≥2 annotators agree (≥3 for holdout). Situational tags come from remapping existing Expresso/EARS emotion labels. Style prompts are generated from tag sets using Mistral-7B-Instruct-v0.2.

**PSC-Scaled (2427 hours, automatic).** Two separate scaling pipelines applied to the 45k-hour Emilia dataset:

- *Intrinsic scaling:* Compute per-speaker median embeddings using VoxSim (a perceptual speaker similarity model trained on human similarity ratings). Emilia speakers with cosine similarity ≥0.8 to a VoxCeleb speaker inherit that speaker's intrinsic tags. This 9× multiplies intrinsic data (to 2518 hours).

- *Situational scaling:* A three-stage cascade: (1) Expressivity Filtering using a DVA (dominance-valence-arousal) classifier keeps utterances with extreme DVA values; (2) Semantic Matching uses SFR-Embedding-Mistral to find transcripts semantically aligned with target emotion queries; (3) Acoustic Matching uses Gemini 1.5 Flash as an audio LLM to rate on a 5-point Likert scale whether the speech acoustically matches the target emotion — retaining only 5-rated examples. This 3× multiplies situational data (to 215 hours).

**TTS model.** Parler-TTS (880M params, autoregressive DAC token prediction with Flan-T5-Large as text/style encoder) fine-tuned on ParaSpeechCaps. Classifier-free guidance (scale 1.5, zero-tensor unconditioned prompt) applied at inference to improve style adherence — effective even without CFG dropout training.

## Key Results

Table 3 compares models on a 246-example holdout set with one rich tag per example, evaluated by Amazon MTurk annotators:

| Model | Consistency MOS | Intrinsic TR | Situational TR | Naturalness MOS |
|---|---|---|---|---|
| Parler-TTS (baseline) | 3.05 | 33.0% | 21.2% | 2.85 |
| +LibriTTS-P,Exp,EARS (best baseline) | 3.55 | 40.7% | 69.7% | 3.10 |
| PSC-Base model | 3.75 | 63.6% | 68.1% | 3.27 |
| PSC-Scaled model | 3.83 | 69.5% | 75.4% | 3.58 |

Gains over the best baseline: +7.9% Consistency MOS, +28.8pp Intrinsic Tag Recall, +5.7pp Situational Tag Recall, +15.5% Naturalness MOS. All improvements are statistically significant at 95% CI.

The human evaluation validates the automatic scaling: PSC-Scaled achieves comparable tag recall to PSC-Base (50.3% vs. 48.7% intrinsic; 71.3% vs. 68.1% situational), confirming the automatic annotations are of human-annotation quality. Using a standard WavLM ECAPA-TDNN embedder instead of the perceptual VoxSim embedder drops intrinsic recall to 45.3%, validating the perceptual similarity approach.

Compositional prompts (12 intrinsic × 10 situational × 2 genders = 240 combinations) show the Scaled model generates both tag types correctly most frequently, outperforming the Base model and the best baseline.

## Novelty Assessment

The primary contribution is the dataset and its two-pronged automatic scaling pipeline. The perceptual speaker similarity approach for intrinsic tag propagation is novel and practically well-motivated (standard speaker verification embeddings would conflate identity with style). The three-stage situational pipeline (DVA filter → semantic matching → acoustic matching via audio LLM) demonstrates that VLMs/audio LLMs can serve as quality filters for subjective style annotations. The TTS modeling contribution is incremental — Parler-TTS is used as-is, with CFG at inference as the only new modeling element. The dataset is the primary deliverable, released publicly.

## Limitations and Open Questions

Coverage is English-only; style-prompted TTS in other languages remains unexplored. The dataset has inherent demographic biases (shrill overrepresented for female speakers; guttural for male), which could be amplified in trained models. Intelligibility drops for models trained on rich style data (WER 8.63% for Scaled model vs. 4.47% for LibriTTS-R baseline), reflecting genuine style fidelity for naturally less-intelligible styles (non-American accents, slurred speech). The field lacks reliable automatic metrics for style consistency — all evaluation requires expensive human annotation.
